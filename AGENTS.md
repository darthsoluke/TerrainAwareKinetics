# Working in TerrainAwareKinetics

- Execution sessions start at `handoff/CURRENT.md`: it points to the one task file to execute. Follow `handoff/README.md` for status updates; instructions are not pasted into the chat.
- Read `docs/START_HERE.md` and the latest result/hand-off linked by `README.md` before changing models or interpreting results.
- This is the project source/documentation repository. Keep navigation readable and update the appropriate directory README when adding an entry point.
- Preserve experimental provenance. Distinguish raw recordings, mirrors, windows, exposures, optimizer updates, trained checkpoints and design proposals.
- Keep source motion, generated motion and actual physical execution clearly identified.
- Preserve existing experiments and failed results. New training requires an explicit bounded plan, source/data identity and the established preflight gates.
- Use only resources currently authorized by the user. Hardware connection details belong in private local configuration.
- Publish source/docs and small aggregate results only. Keep model weights, motion/scene data, caches, credentials and private infrastructure details outside Git.
- Do not promote a model using average reconstruction loss alone. Preserve the control, source-contact, full-skin geometry and local real-time acceptance gates.
- Use plain language in documentation. State concrete findings and their evidence; avoid defensive writing and claims stronger than the experiments support.
- Do not load the disabled Superpowers workflow skills.
