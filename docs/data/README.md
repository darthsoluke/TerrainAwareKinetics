## 先理解四种数量

1. **原始录制**：真实采到的一段动作。
2. **派生动作**：镜像、转换骨架或改变体型后得到的版本。
3. **窗口**：从一段动作中截出来的小段，相邻窗口可能高度重叠。
4. **曝光**：模型使用一次样本；重复使用会增加曝光，不增加新录制。

模型训练、验证和测试按原始录制家族分组。同一来源的镜像、体型和重叠窗口保持在同一划分。统计量仅使用训练集生成。

## 准备资源

源码不包含动捕、权重、场景网格和缓存。已有内部版本通过原制品存储准备；公开数据从各作者入口取得，并保留相应许可和版本。

当前代码常见路径角色是：

```text
out/                    本机外部依赖、模型和演示制品的运行位置
data/                   自行准备的数据根目录
runs/                   自己新建的训练与评估输出
private/                本机连接和制品访问配置
```

这些目录不进入Git。历史脚本的模板路径需按本机配置设置，实验运行时应绑定实际数据清单和哈希。
