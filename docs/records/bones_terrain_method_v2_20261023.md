# BONES-SEED 动作—环境配对方法 v2

2026-10-23。本文是 BONES-SEED 地形拟合阶段的完整方法说明，取代 [阶段计划](bones_terrain_fitting_plan_20261022.md) 中分散的设计讨论；
该计划文件保留每一步的审查与历史结果。已完成真实 BVH 的四路执行，结果见 [v3 执行报告](bones_terrain_fit_v3_pro6000_20261023.md)：顶棚、侧墙和变体均有实际产物，侧墙与变体质量门尚未通过。
第 9 节记录根据 v3 结果所做的 v4 修订（地面、侧墙、顶棚校准、变体验收），下文各节已按 v4 更新。

## 1. 目标与范围

给 BONES-SEED 的源动作配上能解释它的三维环境，产出"动作 + 场景 + 观测"配对数据，用于训练实时、地形感知的逐帧控制器。

本阶段覆盖：平地、箱体与平台（含已知尺寸 50cm/1m/2.3m）、楼梯、越障、蹲、手膝着地、匍匐、跪、靠墙。
不覆盖：崎岖地面与斜坡（BONES 中没有这类动作，下一阶段从 PFNN、PARC 补充）、窄道行走（没有对应动作，作为已知限制）。

## 2. 原则

1. **动作不变。** 只做已有流程中的骨架解析、30Hz 重采样和官方 FK；动作不编辑、不清洗。所有几何都在源世界坐标（Y 向上，米）。
2. **几何一致。** 环境不能进入身体：以官方 SOMA77 完整蒙皮测量，任一帧穿透超过 2cm 即判不合格。关节球指标只作参考。
3. **环境解释姿态。** 低姿态必须有使高一级姿态无法通过的顶棚；动作在某处迈上迈下，那里就要有对应的支撑边。
4. **行为中性。** 环境中不能出现"本该改变行为、却没有改变"的几何。与动作无关的部分必须留出足够余量（第 5 节）。
5. **防止捷径。** 几何类型不能预测动作类别：直立片段也配高顶棚，所有片段都配远处杂物。
6. **可追溯。** 每条结果记录阈值、源码哈希、输入哈希和失败原因，失败结果保留。

## 4. 各步骤方法

### 4.1 支撑箱体（步骤 3，v2）

- 证据：`stair_support` 的脚底静止支撑面；手掌静止且比髋低至少 0.35m；膝静止且小腿不竖直（脚底不低于膝 0.25m 以上）。
- 支撑层：按高度聚类；与下一层相差小于 6cm 的层并入下层（蹬地造成的假台阶）。
- 每层证据按 0.3m 距离分簇，每簇一个从地面立起的实心箱体。证据矩形若与身体冲突，依次退回"只用脚的证据""单个证据"；仍冲突则放弃该簇并记录。
- 每个箱体给出证据矩形、最小矩形（证据外 3cm）和最大矩形（四边外推到身体为止，最多 0.6m）。

### 4.2 顶棚（步骤 4）

- 身体包络：水平 0.1m 网格，每格记录所有帧中蒙皮的最高点。
- 主导低姿态决定解释上界（相对地面）：蹲与深蹲 < 站立头顶 − 5cm；手膝着地 < 蹲姿头顶 − 5cm；匍匐 < 手膝着地头顶 − 5cm。
  站立头顶取官方蒙皮绑定姿态高度；蹲、手膝头顶取站立头顶的 0.62、0.40 倍（v3 紧顶棚高度的 P5 校准，见第 9 节）。
- 核心区域：低姿态经过、且整段动作身体最高点仍低于上界的格子。演员站立过的地方自然被排除，所以"站→蹲"的片段，顶棚从开始下蹲处起。
- 紧顶棚高度 = 核心区域最高点 + 4cm；松顶棚高度 = 解释上界。两者之间任意高度都合法。若紧高于松，判为"无法解释"并记录。
- 范围：核心区域的有向矩形，再向外推到身体会进入为止，最多 0.6m。
- 解释率：低姿态帧中，髋部位于顶棚下方且顶棚低于该帧姿态上界的比例。
- 原地变换：若没有不与身体冲突的矩形，且超过 20% 的低姿态帧髋部位于"直立时身体到过"的格子上，判为 `unexplainable_in_place_transition`（例如原地跪下再站起）。静态顶棚无法解释这类动作。

### 4.3 侧墙（步骤 4）

在身体静止段，于 24 个水平方向上找最外侧平面，平面位置须稳定（2cm 内）。只有"承重"的接触才算墙：

- 接触部位：躯干（髋、脊柱、胸、肩、上臂）贴在平面 1.5cm 带内的蒙皮点中位数至少 60 个（靠墙），或手部至少 25 个且平面离髋至少 0.35m（撑墙）。部位由每个蒙皮顶点的主导 LBS 关节决定，启动时在绑定姿态上校验。
- 双脚离平面至少 0.15m。脚贴着平面时，平面不承重，只是身体的外缘。
- 墙沿切向扩展到身体越过平面为止；若为清空身体须外移超过 5cm，放弃该候选。
- 最终墙体用完整蒙皮复核，任一帧穿透超过 2cm 即丢弃（记为 `dropped_penetrates_skin`）。

墙高 2.5m，厚 0.2m。

### 4.4 场景变体（步骤 5）

每条片段默认采样 4 个场景。一个场景合格需同时满足：

1. 除地面外的任何实体都不进入蒙皮超过 2cm；
2. 每块脚底支撑证据的中心下方都有表面，且高度与该证据所属支撑层相差不超过 3cm；
3. 片段若有持续低姿态，顶棚解释率至少 0.9。

不合格原因逐条记录。片段级别分三类：`environment_explained`（至少一个合格场景）、`geometry_only_low_posture_unexplained`（几何一致，但低姿态没有环境原因，例如原地跪下）、`rejected`。第二类单独存放，不混入地形驱动的训练数据，避免模型学到"无故下蹲"。

| 元素 | 采样范围 |
| --- | --- |
| 支撑箱体每条边 | 证据外 0.3m 到最大位置之间；若最大位置比中性下界还近，说明动作约束了这条边，取最大位置 |
| 拟合顶棚 | 紧、松高度之间；水平范围用紧顶棚的范围（对更高的顶棚也合法） |
| 侧墙 | 拟合结果原样保留 |
| 直立片段的高顶棚 | 以 50% 概率加入，高度在"身体最高点与站立头顶的较大者 + 0.15m"到 3.0m 之间，覆盖整条路径外 1m |
| 杂物（墙、柱、箱） | 0~4 个，0.3~1.5m 见方、0.3~2.5m 高；离身体包络与"前视区"至少 0.3m |

前视区：沿片段最后 0.5 秒的速度方向再延伸 1 秒。片段结束时模型仍在向前看，前方不能出现动作没有反应的障碍。

## 5. 行为中性余量（候选值）

| 项 | 值 | 理由 |
| --- | --- | --- |
| 支撑边超出证据 | ≥ 0.3m | 脚贴着边沿时人会小心落脚；BONES 中的箱体动作没有这种反应 |
| 直立动作的头顶余量 | ≥ 0.15m | 擦头而过会引起低头 |
| 杂物离身体 | ≥ 0.3m | 太近会引起避让 |
| 顶棚解释余量 | 5cm | 顶棚须明显低于高一级姿态 |

数值写在 `SceneConfig`，随每次运行记录。运行后用靠墙片段的离墙距离、越障片段的起跳距离等数据复核。

## 6. 泛化设计与评测接口

- **同一动作，多种场景**：变体之间只改与动作无关、但在中性范围内的几何，模型应学到对这些变化不敏感。
- **防捷径**：直立片段一半配高顶棚，低姿态片段也配杂物，使"有没有顶棚、有没有杂物"不能预测动作，只有"顶棚多高、离多近"能。
- **可分层留出**：每个变体记录几何参数（支撑边、顶棚高度、直立顶棚高度、杂物数）。训练集划分时，除演员与录制家族外，还可留出一段几何参数区间只用于测试。
- **训练后的评测**（写入评测协议，不在本次运行范围）：顶棚高度、台阶高度扫参看姿态切换点；无关几何的不变性；数据中没有的组合（楼梯 + 低顶等）单独报告；长时闭环。

## 7. 本次运行的验收门

| 门 | 标准 |
| --- | --- |
| 支撑箱体 | 蒙皮穿透超过 2cm 的片段占比，每组都显著低于 v1；剩余的逐条可解释 |
| 顶棚 | 蹲、手膝、匍匐组中拟合成功率高；紧顶棚解释率中位 ≥ 0.9；拟合顶棚的蒙皮穿透为零 |
| 侧墙 | 靠墙组有拟合结果；平地对照组拟合墙接近零；保留的墙蒙皮穿透为零 |
| 变体 | 按第 4.4 节三条标准验收；各组合格片段比例和不合格原因分布逐组报告 |
| 地面 | 支撑箱体与地面分开统计；记录蒙皮低于地面的深度分布（动捕自身误差），不作为拟合失败 |

## 8. 已知限制

- Uniform 世界按演员体型缩放，所有高度都是 Uniform 世界里的值（见计划文件中的缩放分析）。
- 顶棚是每段一个水平面，混合多种低姿态时按主导姿态解释，其余帧的解释率会偏低。
- 蹲、手膝头顶高度用比例近似（已按 v3 统计校准为 0.62、0.40）。
- 原地低姿态变换没有静态环境能解释，只能作为单独类别保留。
- 姿态分类用阈值规则，深蹲与跪的边界较粗。
- 窄道、崎岖地面没有数据；对应场景只能作为部署时的已知限制。

## 9. v4 修订（根据 v3 执行结果）

| v3 现象 | 原因 | v4 修改 |
| --- | --- | --- |
| 匍匐、手膝、跪组蒙皮"穿透"地面 9~13cm | 地面取最低的脚底支撑层；脚背或脚尖着地时，这一层比膝、手、胸高 | 有蒙皮时，若最低脚底层比"逐帧蒙皮最低点的 P2"高 3cm 以上，地面改用后者；其上 6cm 内的层视为假层丢弃 |
| 同上，脚背朝下的脚被当成 10cm 平台 | 脚底朝上时，sole 区域确实"静止在某个高度" | 若某层每块脚底证据的范围内都有蒙皮点低于该层 3cm 以上，该层判为"脚朝上"，不作支撑（标记 `inverted_foot_level_dropped`） |
| 已知尺寸箱体最大矩形 718 条超过 2cm | 箱体外推用关节球判定自由空间，比蒙皮粗 | 有蒙皮时，自由空间用每 6 个蒙皮顶点取 1 个加脚底区域 |
| 平地对照 80 条约 2cm "穿透" | 动捕蒙皮略陷入地面，被计入支撑穿透 | 指标分为 `skin_support`（支撑箱体，作为验收依据）与 `skin_ground`（只报告分布） |
| 墙体 777 条穿透，平地对照 574/900 条拟合出墙，墙面最多外移 10.8m | 只要求 80 个蒙皮点贴面（全身 18,056 个点），身体外缘本身就满足；外移没有上限 | 第 4.3 节的承重接触条件、脚距、5cm 外移上限和最终蒙皮复核 |
| 变体接受率 86.88%，且缺支撑或解释率为 0 的变体也被接受 | 验收只看穿透 | 第 4.4 节三条验收标准和片段级分类 |
| `no_conflict_free_rectangle` 集中在原地跪、原地爬起等词干 | 低姿态发生在站立过的位置 | 第 4.2 节"原地变换"状态 |
| 紧顶棚高度 P5：蹲 1.078m，手膝 0.715m | 比例 0.72、0.45 偏高 | 改为 0.62、0.40 |
| `on_the_edge` 119/120 条只有一层 | 不是窄支撑数据 | 从后续运行中去掉 |

结构版本：拟合 `bones-terrain-fit-v4`，场景 `bones-terrain-scene-v2`。
