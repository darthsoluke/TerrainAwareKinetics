# 第 7 步：地形感知动作 Transformer 小规模训练计划（待批准）

2026-10-24。本计划需用户批准后才能启动。它是有界的试验，不是正式训练，结果不用于部署或替换已批准的模型。

## 1. 来源与代码

| 项 | 内容 |
| --- | --- |
| 数据 | `runs/bones_env_v1`（[构建与审计记录](bones_env_v1_pro6000_20261024.md)）：训练 5,038 条、31,854 秒、20,149 个场景变体、360 名演员；验证 248 条、15 名演员。只用"环境可解释"片段 |

## 2. 阶段与预算

每卡批量 256，全局 1,024。

| 阶段 | 参数更新 | 样本曝光 |
| --- | ---: | ---: |
| teacher（真实历史，一步监督） | 1,500 | 1,536,000 个窗口 |
| loop:4（自己生成 4 帧） | 500 | 2,048,000 个生成帧 |
| loop:8 | 500 | 4,096,000 |
| loop:16 | 500 | 8,192,000 |
| 合计 | 3,000 | — |

学习率 3e-4，前 200 步预热后余弦下降；critic 学习率 1e-3；梯度裁剪 1.0。墙钟上限 3 小时（`--max-hours 3`），到时所有卡在同一次更新停下并保存。按审计中的单卡计时估算约 0.5–1 小时。

## 3. 预检（启动前必须通过）

1. 81 项相关测试通过（含新增的训练步骤测试）。
2. 单卡冒烟：`--phases teacher:5 loop:4:5 --batch 16 --max-hours 0.2`，确认 progress、eval、检查点写出，损失有限。
3. 从冒烟的 `latest.pt` 用 `--resume` 再跑 2 次更新，确认更新计数和账本连续。
4. 4 卡冒烟：`--phases teacher:5 --batch 64`，确认多卡同步和时间上限同步。

## 4. 验收（试验性诊断，不是部署门）

在固定的一批验证窗口上，每 250 次更新评估一次；最终值如下：

| 指标 | 通过条件 |
| --- | --- |
| 数值 | 全程无非有限值；未因时间上限中断，或中断后已保存 |
| 一步全身误差 | 低于"保持上一帧"基线至少 30% |
| 16 帧闭环根节点漂移 P50 | 低于初始值，且 < 10 cm |
| 16 帧闭环关节穿透（>2cm 的帧比例） | ≤ 1% |
| 16 帧闭环骨盆高度误差 | < 5 cm（低姿态片段不站起来，直立片段不蹲下） |
| 闭环滑步、支撑代价 | 低于初始值 |

任何一项不通过，都保留结果、记录原因，不追加预算，回到设计讨论。

## 5. 不在本次范围

- 长时（> 0.5 秒）闭环、松杆停下、摇杆改变方向时的行为：需要在源指令之外随机改变指令，后续计划再做。
- 3080 上的实时性能：审计测得 PRO6000 上单角色一步（未优化、逐操作执行）P50 12.9ms、P99 17.0ms，超出 60fps 预算，需要单独优化（CUDA graph、减少表示转换）。
- 部署、替换已批准模型。
