## 1. v3 说明了什么

| 现象 | 解读 |
| --- | --- |
| 几何滑步代价下，着地脚速度降到 0.008 m/s，但脚底贴地的比例从源动作的 32% 降到 2% | **模型钻了空子**：把脚抬离地面，几何滑步代价就不起作用。支撑代价又按模型自己预测的着地概率加权，同样可以绕开。v3 计划里设的"着地比例"门正好抓住了这一点 |
| 一步误差 1.06cm，比"保持上一帧"还差 | 滑步权重 100 压过了其他项 |
| **只做一步监督、还没有任何闭环训练时，贴地的脚就已经以 0.17 m/s 滑动**（源动作 0.014 m/s），贴地比例却正常（31%） | 滑步不是闭环训练造成的，一步监督阶段就有了：一步损失分别比较"相对根节点的关节位置"和"根节点位移"，两者各有小误差，叠加起来就是支撑脚在世界坐标里滑动 |

## 2. 改动

| 改动 | 代码 |
| --- | --- |
| 一步监督加"支撑脚位移"项：在源动作标为着地的脚跟/脚尖上，直接比较生成帧与源帧在世界坐标里的脚底水平位移（权重 1.0，按 1cm 归一） | `--foot-weight 1.0` |
| 闭环阶段的支撑和滑步改用源动作的着地标记加权（源帧有效时），不再用模型预测；模型抬脚会被支撑代价惩罚，不着地也躲不开滑步代价 | `--contact-source source` |
| 支撑权重 20 → 2500（悬空 2cm 时代价约 1）；滑步回到按着地加权，权重 100（0.1 m/s 时约 1） | `--support-weight 2500 --skating-mode contact --skating-weight 100` |

一步监督混合 1.0、穿透权重 2500 不变。

## 3. 运行方式与预算

因为一步监督阶段本身就要改，**从头训练**，与 v1 相同的完整阶段：teacher 1,500 + loop:4/8/16 各 500，共 3,000 次更新。A100 两卡，每卡 512，上限 3 小时，预计约 50–60 分钟。另外在一步监督结束时（第 1,500 次）单独评估，和 v1 的一步监督检查点比较滑步，确认新项本身的效果。

## 4. 验收

与 v3 第 4 节相同（一步误差比基线低 ≥ 30%；漂移 P50 < 10cm；穿透 ≤ 源 + 0.5 个百分点；骨盆 < 5cm；各看各的脚口径下着地脚速度 ≤ 源 × 1.5 + 0.05 m/s 且贴地比例 ≥ 源的一半）。另外要求：第 1,500 次的一步监督检查点，贴地脚速度低于 v1 同位置的 0.170 m/s。
