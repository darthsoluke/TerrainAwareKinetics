# 当前 Native Terrain 模型：训练覆盖与推理缺口诊断

本轮诊断已完成。当前 28942 的已认可模型、运行服务和控制参数保持原状；没有训练、IK、Root 替换、碰撞投影或输出平滑。A100 只读诊断进程已结束，完整模型张量哈希检查通过。

结论：模型确实使用地形信息，但最新小样本训练对低速楼梯、前进平地动作、方向及连续生成历史的覆盖不足。训练窗口表现不能代表新路线或持续 WASD。双路环境条件的贡献不对称，不能据此直接删一路；当前应优先修数据选择和控制覆盖，而不是直接扩大相同配方或改运行时。

## 2. 换几何是否影响模型

固定四帧历史、水平命令、权重和推理设置，把场景换成当前支持高度的平面，重算两路环境观测：

- 上楼窗口起点 32：Root planner 高度最大差 37.78cm，最终解码 Root 高度最大差 6.03cm。
- 下楼窗口起点 36：Root planner 高度最大差 81.94cm，最终解码 Root 高度最大差 47.28cm。
- 六个 BONES 平面窗口的平面自对照差 0。

因此“Root 完全不看地形”不成立。planner 与最终解码动作的响应也不等量，例如上楼起点 24 的 planner 差 13.40cm，但最终解码高度差只有 0.22cm。这提示需要继续审查 Root→Pose→codec 的条件依赖；不能把 Root 规划响应直接当作最终避障能力。

这是条件干预。楼梯源历史配平面不是干净的平地动作标签，不能据此评判平地质量；没有把该输出用于训练。报告保留了垂直原点差，所有对应窗口均为 0。

## 3. Pose 两路地形输入的贡献

只在独立离线进程临时绕过指定 Pose cross-attention 的残差输出。Root 预测逐值保持不变；每个窗口消融后重跑默认链，确认输出恢复为原值；模型参数哈希不变。

| 消融 | 楼梯训练窗口改变的 tokens | 相对腿部动作最大差 |
|---|---:|---:|
| 关闭旧高度场 Pose 支路 | 109/1024（10.64%） | 0.876cm |
| 关闭新体积 SDF Pose 支路 | 1/1024（0.10%） | 0.0455cm |
| 同时关闭两路 Pose 支路 | 118/1024（11.52%） | 1.037cm |

这里按 8 个时间 token × 8 个量化 head 统计，每窗口 64 个离散码项，共 16×64=1024 项。

当前源历史窗口的 Pose token 选择明显更依赖旧支路。此实验没有关闭体积 SDF 对 Root 或 decoder 的条件，也没有覆盖所有生成历史；不能称体积 SDF 整体无用，更不能直接移除任意一路部署。

## 4. 未参与最新 bank 的路线

在接近首台阶的真实源历史窗口，两个 bank 内来源通过 2/2，八个 bank 外来源通过 0/8。使用原腿部误差 <=1.5cm、最终 Root RMS <=2cm、全蒙皮峰值 <=2cm、无未知/不确定查询的能力门，没有放宽阈值。

10 条路线 × 两种起步的 20 次恒定命令闭环测试，完整路线门通过 0/20。检查真实终帧对应的终点平面、路线偏移、完整 18056 顶点及 8 substeps 精确穿入。到达终点平面本身不等于正确通过；有限 16 秒预算内未完成也不等于必须提高输出速度。

值得保留的失败例：

- bank 内上楼源起步到达终点平面，峰值穿入 14.98cm；idle 起步 30.81cm。
- `generated_22928f55fcd9aa9b-up` 的 idle 起步峰值只有 0.44cm，但未到终点、横漂 89.47cm。
- `generated_2e2f6c378de547aa-up` 的 idle 起步峰值只有 0.77cm，但未到终点、横漂 115.12cm，并记录实际失败原因。
- 其他 bank 外路线中有到达终点但穿入 9.73–52.64cm 的输出，不能当作可用泛化。

这些结果支持“当前 bank 泛化和连续控制不足”。不能单凭一次失败断言模型只有记忆，也不能说这些 PARC 场景就是当前 256 米 authored 地图测试。

## 5. 连续性与后续次序

本轮额外保存了 380 个发布块边界，其中 132 个为新神经生成块，包含关节速度、加速度及包内参考分布。它们是离线动作连续性证据，没有测浏览器时钟、实时输入年龄或预取等待因果。全身最高关节速度可能来自手部，不能用一个最大值直接认定脚步突变根因。

建议按以下顺序准备下一轮受控修复：

1. 修正数据筛选：验证真实前进动作、活动区间、源质量及朝向/速度/步态覆盖；先替换无效类别代表，再增加真实低速上下楼与平地起步示例。
2. 保留当前权重作匹配对照，训练目标和样本合同明确后，做有覆盖的小试验；继续分别检查 codec、Root、Pose 和连续 actor。不要直接扩大原有八片段配方。
3. 保留双路输入作为当前架构事实。若要简化，需对 Root、Pose、decoder 的体积条件分别审计，并在训练/推理两端同步修改，再与保留架构作匹配对照。
4. 最近邻只用于筛恢复候选；必须验证身体、前缀、地形和后续可达性。速度增强也需重建时间轴、速度/接触/目标标签并重新审查，不能只乘命令数值或拼接原源未来。
5. 对跨块突变另做包含真实命令时间戳的串行/预取配对实验；当前后台页 FPS、commit-wait 总计或单次关节速度均不能独立定位根因。
