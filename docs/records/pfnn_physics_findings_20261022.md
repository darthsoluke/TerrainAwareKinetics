# PFNN 帧级生成器：A/B/C 结果及复核

2026-10-22，19:50 复核。C 已完成12次更新及自动分层评估，三臂训练和原监视器均已退出。
本次另做冻结权重的零训练评估，修正评分口径。没有追加训练、恢复P1或部署模型。
原报告保存在 `out/pfnn_ablation_review_20261022/findings_before_review.md`。

## 当前结论

三臂在本次有限训练预算下改善了全身单步拟合，但没有稳定复现源动作的支撑。
统一源接触标签、有效指令区间后，A/B/C 的闭环足速中位数分别为27.94/31.24/31.78cm/s，
相同源支撑区间参考足速为2.53cm/s。Transformer C仍有较低的运动速度。
这支持优先解决支撑/时间一致性，不支持“注意力无效”“Transformer无法胜任”
或“1cm漂移只有1.12%惩罚已证明唯一根因”。

## 需要纠正的解释

### 1. 48行不是48个独立录制样本

实际选中12个原始source/start窗口，每个有四方向增强，共48行。
三个家族分别为LocomotionFlat02（32行）、LocomotionFlat08（8行）、
WalkingUpSteps05（8行），还存在相邻/重叠窗口相关性。
1484个足部时刻不能直接代入独立样本的中位数标准误公式。
需要按原窗口或录制家族聚类，并用多训练seed区分训练方差。

`/tmp/_power.sh` 的200次随机切分是在汇总的足速标量池里取24个和24个标量，
不是每组24个独立窗口，也没有构造特定效应下的检出率。
因此原3.30cm/s只对应那个标量随机切分统计量，不是通用显著性阈值或统计功效。
不能用它判断不同口径P50、W1或不同架构的排序。

### 2. A/B初始化没有匹配

实际代码先给B构造注意力层，消耗随机数，随后再初始化GRU和共享头。
CPU复核同seed2333时，history_encoder、GRU、Root/path/pose/contact共享层已有14个
tensor不同。零初始化注意力输出只保证“同一个基础模型加零残差”不改变输出，
不能保证两个独立构造的模型初始相同。
A/B目前是单seed的配置对照，不是共享初值锁定的纯注意力消融。

C参数量约为A的一半，并采用无持久GRU状态的16帧窗口。
这种结果不能决定Transformer的优劣；差异原因也不能直接指定为容量。
更宽模型是否改善，须在匹配训练目标、初始化策略和预算的比较中验证；
“至少10倍样本”不是由此次实验推出的必要条件。

### 3. 1.12%遗漏了损失项

原计算仅包含body_fk。实际source_one_step_loss还有权重0.25的
boundary_joint_velocity，它对同一空间误差也有惩罚。
在零误差附近，四个足关节的XYZ各偏1cm时：

| 分量 | 加权loss |
| --- | ---: |
| body_fk |0.002667 |
| boundary_joint_velocity |0.006000 |
| 两项合计 |0.008667 |

此时每只脚的欧氏偏移是1.732cm。若仅一个轴偏1cm，两项分别为
0.000889和0.002000，合计0.002889。该探针只改变输出坐标，
尚未包括真实FK扰动引起的旋转项及实际已有残差的交叉影响。
总loss占比也不能替代参数梯度、优化方向或受控训练干预。

body_fk的二次区间里，5cm相比1cm有25倍loss、5倍梯度。
所以“加25倍权重获得同等梯度”原推导混淆了loss和梯度。
支撑专用监督仍是合理候选，但它尚未被证明是唯一原因，也不能统一解释
另一条离散体积支路的1/1024变化现象。

### 4. 单步位置误差不能直接换算闭环滑移

若p_hat(t)=p_source(t)+e(t)，则速度误差取决于30×[e(t+1)-e(t)]。
常量1cm位置偏差在第一边界之后可以没有持续速度误差。
原1.117cm×30=33.5cm/s与37.3cm/s接近，只是量级对照，
跨了teacher/closed、不同contact mask和不同统计方式，不能确立机制。
新增测试明确覆盖常量位置偏差、正确端点接触mask和边界计入。

### 5. 原力旋量/摩擦指标暂停用于物理结论

源码复核发现：

- segment_com_world使用R转置乘绑定偏移；本库FK使用列向量R乘偏移，
  两者旋转约定不一致。
- analyse在双脚支撑时虽然收集了4个足关节点，构造接触片仅用base[0]/base[1]，
  丢掉第二只脚；将“无解”归因为真实力臂不足没有依据。
- 两次中心差分仍纳入由补零边界速度污染的时刻。
- 残差求解未检查SLSQP是否成功，直接返回result.x结果。
- 角动量仅含轨道项，缺少各段自旋惯量项；角残差单位是m²/s²，
  不是线残差的m/s²，两者未经显式尺度处理直接平方相加。
- 摩擦采用方锥近似，不是圆形库仑锥；足面法线统一竖直。
- 参考审计与rollout入口的代理清洗流程不一致。

因此20/20构造LP检验只验证了所选矩阵/解算子上的可行例，
没有验证从姿态构造质心、双脚接触、角动量和边界导数的整条链。
原“完全可行帧4.0%/1.7%/0.8%”和参考残差仍归档，但不再用于物理排名。
分段质量扰动不敏感，也不能证明代理质量或惯量正确；
带符号四面体出现负项本身不能直接推出质量误差。
