## Mechanism And Evidence

The15 SOMA landmarks cover feet/toes/knees, wrists/finger ends/elbows, head,
chest and pelvis. Exact signed prism queries represent the observed heightfield
solid, including step sides. This is not a general3D scene SDF and cannot model
overhangs. Unknown map regions remain explicitly unknown.

SDF features enter Root/Pose BEFORE their Transformers and the decoder input.
Four played history frames and24 future FK frames from the model's own proposal
are queried. Source future pose/height never enters these queries. Existing
heightfield conditioning remains. A flat-reference feature residual preserves
the frozen flat controller. Native MB token masking/incorrect-token noise spans
the actual denoising training objective, replacing final-step-only token CE.

The literature basis is the existing reviewed official PARC pre-Transformer
scene fusion, native MB masking code, and DART generated-history training;
see terrain_tokenization_literature_20261010.md. This is our explicit adaptation,
not a claim of reproducing a published SDF/MB method.

Each row advances its own factual clip, up to13 primitives.65-frame clips retain
their5 valid primitives without shortening129-frame rows. The real-data smoke
recorded118 completed13-primitive episodes on rank0 by update16. No padding.
Only an unknown observation permits a counted same-time source reset in training;
evaluation never resets or fills failed output.

PARC and category-balanced BONES each have50% episode probability. Actual
primitive exposure is reported separately. Weak constant cruise intent is inferred
only when a real straight flat approach exists before terrain. Otherwise ordinary
source-derived velocity/facing labels apply. This avoids always telling the model
the slowed outcome as if it were the requested speed. These are weak labels,
not recorded user controls. Training/runtime both use rolling SoftCommandState.

## Verification And Limits

Ten focused SDF tests and six existing live/runtime-control tests passed after
the final local changes. The web-default test verifies options against training
forward. Tests cover analytic signed distances, gradients,
unknown regions, vectorized/scalar equality, no target leakage, pre-Transformer
gradients, yaw/scene alignment and independent-row sampler replay.

Two-GPU6-update versus3+3 replay preserved both ranks' RNG and sample counts
exactly. Fast CUDA max parameter difference was2.185e-6; stored full motion-feature
history max difference2.306e-4. The strict2e-6 floating comparison FAILED, so do
not claim bitwise replay. A deterministic diagnostic failed because official MB
uses cumsum_cuda_kernel, unsupported by PyTorch's strict deterministic mode.
Production retains the normal fast kernels; state is fully restored, floating
arithmetic is not promised bitwise. Diagnostic logs and checkpoints are retained.

Batched prism distance/normal/gradient tests match the scalar reference. Cache
capacity is bounded by max(96,2*batch). Single-card128-row throughput increased
from about39 to66 examples/s after packing/caching, but full DDP must be measured.

The evaluator distinguishes known point occupancy from uncertainty about the
nearest surface beyond a map boundary. Penetration uses exact negative SDF where
certified and conservative vertical fallback elsewhere in a known cell, matching
training. It reports both unknown occupancy and uncertified nearest distances.
Its566 sampled skin vertices are not a full-surface collision guarantee.
