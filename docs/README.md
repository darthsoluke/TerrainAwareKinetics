# 文档导航

如果你是第一次了解项目，请先读 [项目全景](START_HERE.md)。它从操控角色这个目标讲起，再解释数据、训练、模型与目前结果。

| 路线 | 入口 | 读完能了解什么 |
| --- | --- | --- |
| 入门 | [START_HERE](START_HERE.md) | 不熟悉机器学习时也能理解整个项目 |
| 数据 | [data](data/README.md) | 已有资源、训练子集、场景与增强数量 |
| 模型 | [architecture](architecture/README.md) | 各代实际架构及尚待实现的设计 |
| 过去的实验 | [history](history/README.md) | 路线演进、已完成训练和重要结果 |
| 研究问题 | [research](research/README.md) | 闭环、地形响应、接触与物理关系 |
| 开发 | [development](development/README.md) | 环境、依赖、复现和源码快照 |
| 详细记录 | [records](records/README.md) | 每份原始研究/执行文档的索引 |

详细记录中的“当前”指那份记录的写作时刻。后续复核可能修正旧结论，最新结果优先从仓库首页进入。
